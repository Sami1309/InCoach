Create a simple app that does the following

1. Uses Gemini flash live to get user voice input
2. dispatches agents (on Gemini 3.5 flash) on user command to create a drill/workout plan for the user. Searches youtube videos and gets clips/screenshots from them, then designs a UI (from templates) to structure the workflow
3. Acts as a live coach during the exercise interacting via voice (it talks to you), and the webcam

DOCS.md has info on the API


# User Interface

UI Should be CLEAN, MINIMAL, and professional. MVP for this should be for a golf app. Avoid visual clutter, make the interface joyful and responsive, cyber-bougie style

Some general guidance for what is impressive

Focus on these especially
  1. Real agent events streamed to cockpit (sells Live Demo + Originality).
  2. MediaPipe pose overlay + selected-frame Gemini contact classify (sells Live Demo).
  3. Visible validator diff + YouTube-URL ingest (sells Originality).
  4. Memory recall on re-open + one-sentence platform/market line (sells Impact).
  5. Gemini Live voice last — high reward, but only if 1–4 are solid, because it's the
  most fragile thing on stage.
